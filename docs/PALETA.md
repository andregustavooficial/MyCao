# MyCão — Paleta de cores (rascunho)

Cores escolhidas: **Azul 500** e **Azul 600** (escala Material Design Blue).
Valores medidos na imagem: ~#4BA6EE e ~#4497E0 (clareados pela compressão); correspondem a:

| Tom | Hex | Uso sugerido |
|-----|-----|--------------|
| Azul 50  | #E3F2FD | Fundos suaves, cards |
| Azul 100 | #BBDEFB | Fundos de destaque |
| Azul 300 | #64B5F6 | Gráficos, ícones secundários |
| **Azul 500** | **#2196F3** | Cor principal (marca, barras, destaques) |
| **Azul 600** | **#1E88E5** | Cor principal alternativa / pressionado |
| Azul 700 | #1976D2 | Botões e textos sobre branco (contraste acessível) |
| Azul 900 | #0D47A1 | Títulos, modo escuro |

Matiz: ~207° (azul-celeste). Complementar: ~27° (laranja).

| Função | Hex |
|--------|-----|
| Destaque complementar (laranja) | #FF8A3D |
| Normal / melhora (verde) | #43A047 |
| Atenção (âmbar) | #FFB300 |
| Alerta / acima de 30 rpm (vermelho) | #E53935 |
| Preto (texto) | #121212 |
| Cinza escuro | #424242 |
| Cinza médio | #9E9E9E |
| Cinza claro (fundo) | #F5F5F5 |
| Branco | #FFFFFF |

Obs.: texto branco sobre #2196F3 tem contraste baixo (~3:1); para botões com texto, preferir #1976D2.
